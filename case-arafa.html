Work / Islamic fintech

ArafaArafa

a structured way to save for Umrah.

A savings and booking platform built around one idea: Umrah should be planned for on purpose, with a clear savings target, transparent Shariah-compliant packages, and no guesswork about where the money goes.

Role
UI/UX Designer
Type
Concept project
Platform
Web & mobile app
Focus
Islamic fintech

The context

Saving for Umrah is usually informal.Saving for Umrah is usually informal.

Most people save for Umrah the same way they save for anything else, a little at a time, without a fixed target or a clear view of package pricing until they're already deep into planning. Arafa turns that into a structured fund: a savings goal, eKYC-verified identity, and packages priced and compared up front.

What I designed

Trust signals that don't feel like paperwork.Trust signals that don't feel like paperwork.

  • A homepage hero built around the actual product screen: savings progress, eKYC status, and nearby-to-Haram hotel options, not a generic app-store mockup.
  • A dark emerald visual system chosen deliberately over the expected bright-green, mosque-silhouette look common in Islamic apps.
  • A dedicated features page that explains eKYC verification and Shariah-compliance in plain language, since both are reasons people hesitate to commit money.
  • Stat framing (Muslims worldwide, distance to Makkah, the size of the Islamic economy) used to size the problem without resorting to invented numbers.

Outcome

A site built to earn the first deposit.A site built to earn the first deposit.

Home, features, and contact were designed as one connected flow, so someone landing on the hero and someone reading the full feature breakdown arrive at the same trust conclusion. The result is a marketing site that reads less like an app pitch and more like a fund someone would actually commit money to.
